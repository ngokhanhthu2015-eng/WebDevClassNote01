# The Language of Flowers

## About the Project

The Language of Flowers is a website exploring floriography, the language of flowers. It helps visitors discover the meanings and messages associated with different flowers and how they can express emotions that are difficult to put into words.

## Features

- A homepage introducing floriography
- A gallery of flowers and their meanings
- A flower story section exploring symbolism and occasions
- A contact form for visitors to share their stories
- Responsive layout for desktop and mobile screens
- CSS hover effects and custom color variables

## Technologies

- HTML
- CSS
- CSS Flexbox and Grid
- CSS media queries
- Google Fonts

## Project Structure

- `index.html` — Website structure and content
- `style.css` — Website styling and responsive layout
- `images/` — Local image assets, if applicable
- `Midterm/` — Midterm documentation and presentation
